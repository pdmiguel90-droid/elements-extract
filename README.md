# Elements Extract — FFmpeg

> Descargaste una película o una serie… y le falta algo: **el subtítulo en tu idioma**.
> **Translating subtitles for your movies & series, 100 % offline.**

**Elements Extract** es un extractor gráfico de pistas (audio, vídeo, subtítulos) con traducción de subtítulos **totalmente offline**, sin depender de internet para encontrarlos.

> 🛠️ **Desarrolladores:** el mantenimiento, reemplazo y refresco de los modelos de traducción se documenta en [docs/modelos.md](docs/modelos.md).

## ¿Por qué existe este proyecto?

Este proyecto nació de una necesidad personal: cuando descargo una película o una serie y esta no tiene el subtítulo que quiero, poder usarlo como **herramienta offline** para traducirlo — **sin depender de internet** para encontrarlo.

Con **Elements Extract** los subtítulos se traducen en tu propio equipo, con privacidad total:

- 🔒 **Tus archivos nunca salen de tu máquina.**
- 🌍 **Traducción local** con modelos de traducción neuronal (bergamot-translator).
- 📼 Extrae audio, vídeo y subtítulos de tus archivos en lote.

**Más detalles en cada versión del README según tu idioma.**
