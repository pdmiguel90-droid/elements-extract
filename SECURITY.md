# Política de seguridad / Security policy

## Versiones soportadas / Supported versions

| Versión | Soportada |
|---------|-----------|
| 1.2.x   | ✅        |
| < 1.2   | ❌        |

## Reportar una vulnerabilidad / Reporting a vulnerability

**No abras un *issue* público** para vulnerabilidades (ejecución de código,
lectura/escritura fuera de lugar, exfiltración — la app ejecuta `ffmpeg`,
`curl`, `tar` y el binario `bergamot`).

Abre un **[Security Advisory](https://github.com/pdmiguel90-droid/elements-extract/security/advisories/new)**
privado en GitHub con:

- versión afectada y sistema operativo,
- pasos para reproducir o prueba de concepto,
- impacto estimado.

Objetivo de respuesta: 7 días. Se dará crédito salvo que pidas lo contrario.
